# S3 plot method for objects of class "rdif" Plots the rho function of the output from rdif.

S3 plot method for objects of class "rdif" Plots the rho function of the
output from rdif.

## Usage

``` r
# S3 method for class 'rdif'
plot(x, ...)
```

## Arguments

- x:

  A saved output from
  [`rdif()`](https://peterhalpin.github.io/robustDIF/reference/rdif.md)
  that is to be plotted.

- ...:

  Additional arguments to be passed to
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html)

## Value

The input object, returned invisibly. Called for plotting side effects.
