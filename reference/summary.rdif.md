# S3 summary method for objects of class "rdif"

S3 summary method for objects of class "rdif"

## Usage

``` r
# S3 method for class 'rdif'
summary(object, ...)
```

## Arguments

- object:

  An object of class 'rdif', a saved list of values from
  [`rdif()`](https://peterhalpin.github.io/robustDIF/reference/rdif.md)

- ...:

  Additional arguments passed through from the generic.

## Value

A printed summary of values

## Examples

``` r
if (FALSE) { # \dontrun{
mod <- rdif(rdif.eg)
summary(mod)
} # }
```
