# The least trimmed squares (LTS) estimate of location

The least trimmed squares (LTS) estimate of location

## Usage

``` r
lts(y, p = 0.5)
```

## Arguments

- y:

  a vector of data points.

- p:

  the proportion of data points to trim.

## Value

The LTS estimate of location of `y`.
